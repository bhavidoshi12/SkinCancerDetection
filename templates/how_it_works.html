How the AI Screening Engine Works

A breakdown of the computer vision and deep learning workflow powering our skin lesion screening platform.

1

Image Ingestion & Strict Validation

When a user uploads a skin lesion image, the backend performs multi-layer validation before any processing begins:

  • MIME & Header Verification: Ensures the file is an authentic JPG, JPEG, or PNG, rejecting arbitrarily renamed or corrupted files.
  • Spatial Resolution Check: Validates that dimensions exceed 50x50 pixels and do not exceed 6000x6000 pixels.
  • Channel Normalization: Converts images to 3-channel RGB, correcting alpha channels and color spaces.
2

Preprocessing & Tensor Rescaling

Dermoscopic images vary significantly in sensor resolution and illumination. Standardized preprocessing prepares input tensors for the neural network:

  • Bilinear Resampling: Standardizes all input images to 224 × 224 × 3 spatial dimensions.
  • Pixel Scaling: Normalizes floating-point pixel intensities to the [0.0, 1.0] interval.
  • Spatial Quality Assessment: Calculates local variance, brightness, and contrast metrics for inspection.
3

Deep CNN Feature Extraction & Classification

The core architecture leverages a Convolutional Neural Network (CNN) configured for dermoscopy feature extraction:

  • Convolutional Filters: Learn spatial hierarchies, identifying border irregularities, pigment globules, and vascular streaks.
  • Softmax Probability Distribution: Generates probability distributions across benign categories and potentially malignant categories.
  • Medical Safety Protocol: When no trained model file is installed, the system switches to an informative Demo Mode rather than presenting fabricated random predictions.
4

Structured Screening Report & Consultation

The user receives an accessible, detailed visual analysis card along with the ability to download a secure PDF screening report:

  • Includes unique report ID, timestamp, and embedded lesion thumbnail.
  • Presents genuine model confidence score (or clearly identifies demo/unavailable mode).
  • Provides a formal recommendation to consult a licensed dermatologist.
